# 분석 1회 단가·가격 산정 (GEO 서비스)

조사일: 2026-09-12 · 환율 1 USD = 1,390 KRW · 원가 근거는 [INFRA_CLOUD_SELECTION.md](INFRA_CLOUD_SELECTION.md) (2026-09-10 조사)

## 0. 결론

**원가는 가격을 결정하지 못한다.** 분석 1회의 변동원가는 유료 전환 후에도 약 2.3원, LoRA distill 후에는 0.4원이다. 어떤 가격을 붙여도 마진율은 99%가 넘는다. 따라서 "5,900원의 근거"는 원가에서 나올 수 없고 **대체재 가격**에서만 나온다. 그 대체재는 크몽의 기본 SEO 진단 리포트(5천~1만원)이며, 5,900원은 우연히 그 밴드 한가운데다. 근거는 있지만 **잘못된 대체재를 고른 근거**다. 사람이 1회 해주는 일회성 진단에 값을 맞추면, 반복 사용이 가치인 SaaS가 일회성 상품으로 포지셔닝된다.

**권장: 단품 5,900원을 주력 상품에서 내리고, 도메인당 월 구독(BASIC 29,000 / PRO 99,000, VAT 별도)을 주력으로 한다.** 단품은 "1회 진단 5,900원"으로 남겨 미가입자 유입용으로만 쓴다. 확대 시에는 가격을 올리지 않고 한도만 늘린다. 원가가 건수에 거의 비례하지 않으므로 볼륨 할인을 사실상 무한히 줄 수 있고, 이것이 크몽·해외 툴 대비 유일한 구조적 우위다.

## 1. 분석 1회 변동원가

`POST /order` 1건 = URL 1개 크롤링 + 로컬 8B 평가 1회 + Gemini JSON-LD 재작성 1회.

| 항목 | 무료 티어 내 (0단계) | Gemini 유료 전환 후 | 절감 후 (§4 적용) |
|---|---|---|---|
| GPU 전기 (로컬 4090, 8B 평가) | 0.33원 | 0.10원 | 0.10원 |
| Gemini 2.5 Flash-Lite 재작성 (입력 8k / 출력 1.5k) | 0원 | 1.95원 | 0원 (LoRA) |
| 스크래핑 대역폭·CPU | 0원 | 0원 | 0원 |
| HTML 원본 저장 (JSONB, 건당 약 150 KB) | 0원 | 약 0.2원 | 0.03원 (gzip+R2) |
| **합계** | **약 0.33원** | **약 2.3원** | **약 0.4원** |

GPU 전기가 저트래픽에서 더 비싼 이유는 유휴 전력이 건수로 나뉘기 때문이다. 1천건/일이면 1만원/월 ÷ 3만건 = 0.33원, 1만건/일이면 2.5만원/월 ÷ 30만건 = 0.083원.

**여기 없는 항목이 진짜 원가다.** 결제 수수료는 건당 원가의 87배다.

| 결제 방식 | 수수료율 | 5,900원 결제 1건당 | 인프라 원가 대비 |
|---|---|---|---|
| 토스페이먼츠 일반 (카드/간편결제) | 3.4% | 201원 | 87배 |
| 영세 가맹점 우대 (연매출 3억 이하) | 0.5~1.15% | 30~68원 | 13~30배 |

## 2. 고정비와 손익분기

| 단계 | 월 고정비 (GPU 감가 제외) | 월 고정비 (감가 7만원 포함) |
|---|---|---|
| 0단계 (OCI 무료 VM, ≤1천건/일) | 약 1.2만원 | 약 8.2만원 |
| 1단계 (유료 VM, 5천건/일) | 약 5.5만원 | 약 12.5만원 |
| 2단계 (1만건/일, LoRA 전환 후) | 약 6.5만원 | 약 13.5만원 |

BASIC 29,000원(VAT 별도, 월 50회) 기준 실수령 기여이익은 약 27,800원이다. 청구 31,900원에서 PG 3.4%(1,085원)와 변동비(50회 × 2.3원 = 115원)를 뺀 값이다.

- **0단계 손익분기: 유료 고객 1명** (감가 포함 시 3명)
- **2단계 손익분기: 유료 고객 5명**

인프라비가 사업의 제약이 아니라는 뜻이다. 사업계획서에 원가율을 자랑하는 대신, 이 숫자는 "고정비가 낮아 가격 실험을 자유롭게 할 수 있다"는 근거로 쓰는 편이 낫다.

## 3. 가격 앵커 세 가지

원가가 하한을 만들지 못하므로, 방어 가능한 숫자는 아래 셋뿐이다.

| 앵커 | 가격 | 함의 |
|---|---|---|
| 크몽 기본 SEO 진단 리포트 | 5천~1만원 (1회) | **현재 5,900원의 실제 출처.** 일회성 진단 시장 |
| 크몽 테크니컬 SEO 진단 + 오류 수정 | 5만~10만원 (1회), 대형 30만원 이상 | 실행까지 포함한 대체재. 우리 제품이 JSON-LD 재작성까지 하므로 여기에 더 가깝다 |
| 크몽 월 정기 유지형 SEO | 월 30만원 이상 | ENTERPRISE 상한 |
| Otterly.AI | €89/월 (약 14만원), 상위 $189~489/월 | 해외 GEO 가시성 추적 self-serve 최저가 |
| Profound Lite | $499/월 (약 69만원) | 엔터프라이즈. 우리 타깃 아님 |
| 고객 내부 대체 비용 | 마케터 2~3시간 × 시급 2~3만원 = 5~9만원 | 분석 1회의 이론적 가치 상한 |

**해석:** 자동 생성 JSON-LD + 점수 평가는 "5천원짜리 리포트"보다 "5만원짜리 진단+수정"에 기능적으로 가깝다. 그런데 5,900원을 받고 있다. 한편 월 구독으로 환산하면 Otterly 14만원의 1/5인 3만원 밴드가 한국 시장에서 자연스럽다.

## 4. 과금 원가 절감 레버 (효과 큰 순서)

| # | 조치 | 절감 | 난이도 |
|---|---|---|---|
| 1 | **단품 결제 → 구독/크레딧 팩**. 결제 건수가 1/10로 줄면 PG 수수료도 1/10 | 결제원가 90% | 상품 설계만 |
| 2 | **영세 가맹점 우대 수수료 신청** (연매출 3억 이하). 3.4% → 1.15% | 결제원가 66% | 신청서 |
| 3 | **LoRA distill로 Gemini 제거**. 이미 인프라 문서의 1단계 계획 | 1.95원 → 0원 | 학습 1회 |
| 4 | **재분석 시 Gemini 스킵**. 점수 검증만 하는 재분석은 로컬 평가만 수행. 재분석 비중 40% 가정 | Gemini 비용 40% | 코드 분기 1개 |
| 5 | **Gemini 입력 토큰 축소**. 스크래핑 마크다운 전문 대신 본문 상위 3k자 + 기존 JSON-LD만 전송 (8k → 4k) | 1.95원 → 1.39원 (29%) | 프롬프트 수정 |
| 6 | **HTML 원본 gzip 후 R2 이관 + 90일 보관** | DB 증가분 제거 | cron |

1번과 2번이 3~6번을 전부 합친 것보다 크다. 인프라를 더 깎을 게 아니라 **결제 구조를 바꿔야 한다.**

## 5. 권장 가격표

전제: B2B이므로 **VAT 별도** 표기 + 세금계산서 발행. 코드에 이미 `Client.ClientPlan{FREE, BASIC, PRO, ENTERPRISE}` enum이 있으므로 구독 4단계가 기존 설계와 일치한다.

### 지금 (0단계, 무료 인프라 + Gemini 1,000 RPD)

| 플랜 | 월 가격 | 분석 한도 | 도메인 | 회당 환산 | 근거 |
|---|---|---|---|---|---|
| FREE | 0원 | 월 5회 | 1 | — | Gemini 1,000 RPD로 무료 유저 약 6,000명 수용 가능(이론), RPM 15 제약으로 실질 수백 명 |
| BASIC | **29,000원** | 월 50회 | 1 | 580원 | 크몽 기본 진단 5,900원의 1/10. 1인 쇼핑몰·소규모 미디어 |
| PRO | **99,000원** | 월 300회 | 5 | 330원 | Otterly €89/월(14만원)의 70%. 대행사·마케팅팀 |
| ENTERPRISE | 월 300,000원~ (견적) | 무제한 + API + 온프렘 | 무제한 | — | 크몽 월 정기 유지형 SEO 30만원 밴드 |
| (부가) 단건 진단 | **5,900원** | 1회 | 1 | 5,900원 | 미가입자 유입용. 결제 후 BASIC 첫 달 차감 크레딧으로 전환 |

단품을 굳이 남기는 이유는 5,900원이 크몽 밴드와 정확히 맞아 "체험 가격"으로는 방어되기 때문이다. 다만 이 가격에 PG 201원이 붙으므로 **매출로 잡지 말고 획득비용으로 회계 처리**하는 편이 정직하다.

### 확대 후 (1만건/일 = 30만건/월, LoRA 전환 완료)

가격은 올리지 않는다. **한도만 늘리고 상위 플랜을 추가한다.**

| 플랜 | 월 가격 | 분석 한도 | 변경점 |
|---|---|---|---|
| FREE | 0원 | 월 10회 | LoRA 전환으로 Gemini RPD 제약 소멸 → 무료 한도 2배 |
| BASIC | 29,000원 | 월 150회 | 동일 가격, 한도 3배 |
| PRO | 99,000원 | 월 1,000회 | 동일 가격, 한도 3배 |
| SCALE (신설) | 299,000원 | 월 5,000회 + API + 우선 큐 | ENTERPRISE 진입 전 단계 |
| ENTERPRISE | 견적 | 무제한 | SLA(서버리스 GPU fallback) 포함 시에만 |

30만건/월을 PRO 1,000명이 소비한다고 보면 매출 9,900만원, 총원가 약 16.5만원, **원가율 0.17%**다. 가격 인하 여력이 무한하므로, 경쟁이 붙으면 가격이 아니라 한도로 대응한다.

## 6. 5,900원을 유지하려면 필요한 것

이 가격을 사업계획서에 그대로 쓰려면 아래 중 하나가 문서에 있어야 한다. 셋 다 없으면 근거 부족이라는 지적이 맞다.

1. **대체재 명시**: "크몽 기본 SEO 진단 리포트 5천~1만원과 동일 밴드, 단 결과가 즉시·자동" — 출처 링크 포함
2. **1인당 구매 빈도 가정**: 5,900원 × 월 N회 = ARPU. N을 근거 없이 잡으면 매출 추정 전체가 무너진다. 구독이면 이 문제가 사라진다
3. **결제 수수료 반영**: 5,900원 매출의 3.4%가 PG로 나간다는 사실이 원가표에 있어야 한다

## 7. 미확정 / 사용자 확인 필요

- 타깃 고객이 소상공인인지 B2B 마케팅팀인지에 따라 BASIC/PRO 밴드가 달라진다. 위 표는 **양쪽 다 수용**하도록 BASIC을 소상공인, PRO를 팀 단위로 잡았다
- 크몽 가격은 크몽 자체 가이드 페이지 기준이며 개별 전문가 견적은 편차가 크다
- 토스페이먼츠 카드 수수료는 가맹점-카드사 계약에 따르므로 실제 계약 시 재확인
- Peec AI 가격은 공개 자료에서 확인하지 못함
