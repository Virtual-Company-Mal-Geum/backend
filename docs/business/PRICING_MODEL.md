## 0. 결론

1. **첫 구매자는 학원 고객을 반복 관리하고 사이트 수정 권한을 가진 웹 제작사·마케팅사·솔루션사다.** 학원은 이들이 관리하는 고객사다. 원장에게 직접 파는 것은 부차 경로다.
2. **시장은 셀 수 있을 만큼 작다.** 실질 파트너 시장은 전국 180~450곳(중심 250~320곳)이고, 1차 영업 대상은 60~80곳이다. 파트너 수를 영업으로 크게 늘릴 수 없으므로 **매출은 객단가가 결정한다.**
3. **상품은 무료 Scan에서 출발해 두 갈래로 나뉜다.** 체험·소규모용 **Remediation Pack**(페이지 건당), 반복 관리용 **Partner**(월 구독). AI 검색 추적은 별도 agent·서비스로 개발할 방향이며 가격은 개발 시점에 정한다.
4. **Partner의 과금 기준은 페이지 수가 아니라 관리 학원 수다.** 파트너가 학원 한 곳마다 돈을 받으므로, 우리도 학원 한 곳 단위로 받아야 파트너가 마진을 계산할 수 있다.
5. **가격(확정, VAT 별도, 수치는 파일럿으로 검증):** Founding Partner 월 290,000원(학원 10곳, 첫 10곳 한정), Partner 월 490,000원(학원 20곳), Partner Plus 월 990,000원~(학원 50곳, 견적). 이전 가격표의 Team 149,000원은 이 시장에서 매출 상한이 너무 낮아 폐기한다.
6. **파트너 설득은 GEO 효과가 아니라 작업 시간 절감에 건다.** 학원 1곳당 2.5만원은 에이전시 직원 약 1시간 인건비다. "학원당 한 달에 1시간만 줄면 본전"을 4주 파일럿에서 숫자로 증명한다(§7).
7. **팔아야 할 것은 점수나 JSON-LD 생성이 아니라 "위치별 수정 diff → 안전 검사 → 재수집 검증"이다.** 분석만 하는 유료 티어는 없다(Adplorer·GeoRank가 URL 진단을 무료로 준다).
8. **원가는 가격을 결정하지 못한다.** Pack 1건 원가는 1~3원이다(생성을 Gemini 유료로 처리하면 약 2.6원).
9. **결제는 한꺼번에 만들지 않는다.** Partner 파일럿은 세금계산서 + 수기 계좌이체로 시작하고, Pack 셀프서브 출시 시 토스페이먼츠 한 곳으로 일반 카드와 간편결제를 연동한다. 카카오페이·토스페이 직접 연동은 거래 데이터가 쌓일 때까지 보류한다(§4.3, §10).
10. **지금 팔 수 있는 건 무료 Scan뿐이다.** 주문 경로는 `/evaluate`만 호출하고, Pack의 개선안·diff·검증과 Partner의 학원별 작업 공간·화이트라벨 보고서는 미구현이다(§10).

### 1.2 첫 구매자 조건

**1순위:** 학원 홈페이지 제작·유지보수사, 교육·학원 전문 디지털 마케팅사, 학원 프랜차이즈 본사, 학원용 LMS·홈페이지 솔루션사

**필수 조건**
- 학원 고객을 여러 곳 보유
- 고객 웹사이트의 HTML 또는 JSON-LD를 수정할 수 있음
- 고객에게 정기 보고서나 개선 서비스를 제공
- 우리 결과물을 자체 상품으로 재판매할 유인이 있음

**후순위·제외:** 일반 기업·공공 SI, 네이버 블로그·플레이스 광고만 운영하는 대행사, 광고 집행만 하고 웹사이트를 수정하지 않는 업체, 학원 고객이 한두 곳뿐인 범용 제작사

**가장 먼저 만날 곳은 이미 GEO·AEO를 팔고 있는 에이전시다.** 피코소프트(GEO 서비스 표기), HOMM·마중(SEO·AEO), 이프론트(AI 검색 구조), 뉴사이트(AI 노출)는 같은 일을 이미 손으로 하고 있어서, 작업 시간 절감을 가장 쉽게 증명할 수 있다.

## 2. 상품 구조

| 상품 | 기능 | 구매자 | 과금 단위 | 상태 |
|---|---|---|---|---|
| **무료 Scan** | 점수, 상위 문제 일부, 이미지 의존 경고 | 누구나 (리드 획득). 파트너 영업 시 그들이 관리하는 학원 사이트 일괄 스캔 | 0원, 횟수·결과 범위 제한 | 판매 가능 (`/evaluate`) |
| **Remediation Pack** | 한 페이지의 전체 문제 + 위치별 HTML·JSON-LD·텍스트 수정 diff + 안전 검사 + 적용 후 재수집 검증 | 파트너 전환 전 체험, 소규모 에이전시, 대형 학원 인하우스 담당자 | 페이지당 건당·크레딧 | 미구현 |
| **Partner** | Pack 기능 + 학원별 작업 공간 + 파트너 로고 보고서 + 팀원 권한 + 승인·적용·롤백 이력 | 1.2 조건을 갖춘 파트너 | 월 구독, **관리 학원 수 기준** | 미구현 |
| **AI 검색 추적 agent·서비스** | 고친 페이지와 연결된 질문을 AI 엔진에 주기적으로 조회해 인용·언급 변화 측정 | Pack·Partner 고객 | 별도 판매 (가격 미정) | 개발 방향 |

**Pack과 Partner를 나누는 기준은 기능이 아니라 반복성이다.** 에이전시는 처음엔 고객사 한 곳의 핵심 페이지를 Pack으로 고쳐 보고, 효과와 작업 흐름이 맞으면 관리 학원 전체를 Partner로 옮긴다. Pack 구매액은 Partner 첫 달 요금에서 차감한다.

**화이트라벨 보고서는 처음부터 넣는다.** 재판매 구조에서는 파트너 로고가 들어간 보고서(PDF·공유 링크)가 판매의 전제다. API는 3곳 이상 유료 요구가 생기기 전에는 만들지 않는다.

**추적은 고친 페이지와 묶는다.** 고친 페이지와 무관한 브랜드 모니터링은 ChainShift·Docenty·Otterly와 정면 충돌한다. 우리 추적은 "우리가 고친 페이지가 인용되는가"에 한정한다.

## 3. 신뢰 설계: 반영 검증과 인용 추적을 분리한다

| | 레이어 1 · 기술 반영 검증 | 레이어 2 · AI 인용 추적 |
|---|---|---|
| 질문 | 패치가 실제 HTML에 들어갔나? 문제가 해결됐나? | AI가 이 페이지를 인용·언급하나? |
| 방법 | 적용 후 재수집 → 스냅샷 diff → 재평가 | 질문 세트를 AI 엔진에 주기 조회 |
| 결과 시점 | 즉시 | 수 주 지연 (가설) |
| 우리가 통제 가능한가 | 예 | 아니오 (모델·지역·개인화 변동) |
| 원가 | 약 1원 (로컬) | 외부 API 조회 과금 — 사용량에 비례 |
| 판매 | Pack·Partner에 기본 포함 | 별도 agent·서비스 |

**추적을 기본 포함하지 않는 이유.** 자체 관찰 실험에서 GEO 점수와 ChatGPT 언급률의 상관은 최고 ρ 0.23, 최대 표본(n=436)에서 0.0007이었고, 실제 학원 적용에서도 인용률이 아직 크게 변하지 않았다. 추적을 모든 고객에게 기본으로 보여주면 **"고쳤는데 숫자가 안 움직인다"를 전 고객이 매주 보게 된다.** 별도 판매로 두면 원하는 고객에게만, 기대치를 먼저 맞춘 뒤 보여줄 수 있다.

**추적 원가는 다른 상품과 구조가 다르다.** Pack·Partner는 로컬 GPU로 돌아 사용량이 늘어도 원가가 거의 그대로다. 추적은 실제 엔진에 물어야 하므로 질문 수·엔진 수·조회 주기에 비례해 외부 API 비용이 붙는다. 따라서 추적 가격은 대체재가 아니라 원가 기반으로 정한다.

## 4. 원가

### 4.1 상품별 변동원가

평가 1회를 **GPU 1단위**로 둔다. 개선안 생성은 출력이 길어(1.5k vs 1k 토큰) 약 1.1단위다. Pack 1건 = 적용 전 평가 1 + 개선안 생성 1.1 + 적용 후 재평가 1 = **최대 3.1단위**(고객이 적용하지 않으면 재평가는 발생하지 않는다).

GPU 전기는 단위당 0.1~0.3원이다. 저트래픽에서는 유휴 전력이 건수로 나뉘어 비싸다(1천건/일 0.33원, 1만건/일 0.08원).

| 항목 | 무료 Scan | Pack (생성 로컬) | Pack (생성 Gemini 유료) |
|---|---|---|---|
| GPU 전기 | 0.1~0.3원 | 0.3~0.9원 | 0.2~0.6원 |
| 외부 API | 0원 | 0원 | 1.95원 (2.5 Flash-Lite, 입력 8k/출력 1.5k) |
| 스냅샷 저장 (gzip+R2, 건당 0.03원) | 0.03원 | 0.06원 (전·후) | 0.06원 |
| **합계** | **약 0.3원** | **약 1원** | **약 2.6원** |

**기본 경로는 평가는 로컬, 개선안 생성은 Gemini다.** Gemini 무료 티어(1,000건/일) 안에서는 생성 원가도 0원이고, 초과분은 유료 호출(건당 1.95원)로 처리한다. 생성까지 로컬로 옮기면 Gemini 비용은 사라지지만 Pack 처리량이 줄어든다(§4.2).

### 4.2 처리량 (팀 기준)

로컬 4090 1대의 일반 평가(피드백 생성) 처리량은 팀 기준 **약 1만건/일**이다. 인프라 문서의 산술 추정 1.5만건/일보다 보수적인 값이다. 개선안 생성은 Gemini API로 처리하므로 로컬 GPU를 쓰지 않는다.

| 상품 | 로컬 평가/건 | 일일 상한 | 비고 |
|---|---|---|---|
| 무료 Scan | 1회 | 약 1만건 | |
| **Pack (생성 Gemini, 기본)** | 2회 (적용 전·후) | **약 5천건** | 모든 고객이 개선안을 적용한다는 보수적 가정. 생성 1,000건/일 초과분은 유료 |
| Pack (생성도 로컬) | 약 3.1단위 | 약 3,200건 | Gemini 비용 0원 대신 처리량 감소. 대안 경로 |

**파트너 기준 용량:** Partner 1곳이 학원 20곳 × 월 10페이지를 모두 쓰면 월 200 Pack, 일 약 6.7 Pack이다. 하루 5천 Pack이면 Partner 약 750곳을 감당하며, 실질 파트너 시장 상단(450곳)보다 크다.

**Gemini 유료 비용:** 450곳이 모두 한도를 채워도 일 약 3,000 Pack이다. 유료 생성은 2,000건 × 1.95원 = 일 3,900원, 월 약 11.7만원으로 Partner 1곳 매출의 1/4이다. 가격·상품 구조에는 영향이 없다. 유료 생성분이 하루 약 1,500건을 넘으면 생성 전용 4090 1대(월 약 9만원, 감가 7만 + 전기 2만)를 추가하는 편이 싸지므로, 그 시점에 선택한다.

**무제한 요금제는 두지 않는다.** 처리량이 병목이어서가 아니라, 남용 방지와 추후 추적 agent가 붙었을 때 사용량에 비례하는 외부 원가 때문이다.

### 4.3 결제 수수료와 수납 전략

**결론:** Partner·Founding 파일럿은 **세금계산서 + 수기 계좌이체**, Pack 셀프서브는 출시 시점에 **토스페이먼츠 한 곳으로 일반 카드 + 간편결제**를 제공한다. PG가 이미 도입된 뒤 Partner 입금 자동화가 필요하면 2% 실시간 계좌이체가 아니라 **건당 400원 가상계좌**를 붙인다. 카카오페이·토스페이 직접 연동은 일반 카드 결제를 대체하지 못하므로 초기 범위에서 제외한다.

#### 계산 기준

- 모든 상품 가격은 VAT 별도다. 고객 결제액은 `VAT 제외 가격 × 1.1`이다.
- PG 수수료는 고객 결제액에 적용한다.
- 아래 손익표는 일반 과세사업자가 PG 수수료의 VAT를 매입세액 공제받는다는 전제로 **수수료 VAT를 제외한 경제적 비용**을 쓴다. 실제 정산액 감소는 표의 PG 비용보다 10% 크다. 예를 들어 Partner 카드의 손익상 비용은 18,326원이지만 정산액은 약 20,159원 줄어든다.
- 수기 계좌이체는 결제 수수료가 아니라 운영비다. 비교를 위해 `입금 확인 2분 × 시급 30,000원 = 건당 1,000원`으로 둔다. 실제 확인·미입금 독촉·금액 불일치 처리 시간은 파일럿에서 측정한다.
- 변동원가는 기본 경로인 페이지당 2.6원을 적용한다.

#### PG 고정비·정산한도

- 토스 공개가는 가입비 최초 1회 220,000원, 연관리비 110,000원이다. 공개 금액 기준 1년 차 330,000원, 월 환산 27,500원이며 실제 VAT 포함 여부와 계약 조건은 견적으로 확인한다.
- 월 정산한도 10,000,000원까지는 보증보험이 면제된다. Partner를 모두 카드로 받으면 19곳부터 월 결제액이 10,241,000원으로 한도를 넘는다. 이후 보증보험료·증액 조건은 공개 정보만으로 알 수 없다.
- 신규 사업자는 일반 수수료율을 먼저 부담하고, 반기별 국세청 과세자료로 영세·중소 등급이 확정되면 PG사를 통해 카드 수수료 차액을 환급받는다. 초기 현금흐름은 일반율로 계산한다.
- 2026년 하반기 연매출 3억원 이하 법정 우대율은 신용카드 0.40%, 체크카드 0.15%다. 그러나 이는 카드사 측 우대율이며 판매자가 내는 **최종 PG 총수수료가 아니다.** PG 자체 수수료가 추가되므로 사업자번호 기준 토스 계약 견적을 받기 전에는 우대율만으로 최종 손익을 확정하지 않는다. 등급 기준은 Pack 카드매출만이 아니라 사업자의 연간매출액이다.

**운영 판단:** 지금은 유료 상품 자체가 미구현이므로 PG 계약부터 시작하지 않는다. Partner 파일럿은 수기 계좌이체로 검증하고, Pack 구매 화면을 출시할 때 토스 PG 하나를 붙인다. Pack에서 PG 고정비를 이미 부담하게 된 뒤 Partner 입금 확인이 반복 업무가 되면 가상계좌를 추가한다.

| **Partner** | **490,000원** | 20곳 | 24,500원 | 기본 플랜. 학원 추가 시 1곳당 월 20,000원 |
| Partner Plus | 990,000원~ (초기엔 견적) | 50곳 | 19,800원 | 프랜차이즈 본사, 대형 대행사. API는 3곳 이상 유료 요구 시 |

**공통 포함:** 학원 1곳당 월 10페이지 수정·재검증, 학원별 작업 공간, 파트너 로고 보고서(PDF·공유 링크), 팀원 권한, 승인·적용·롤백 이력, 연간 계약 없이 월 단위 해지

**결제:** 파일럿과 초기 판매는 세금계산서 + 계좌이체다. 카드·자동결제는 실제 파트너가 계좌이체 때문에 이탈하거나 수납 운영시간이 §4.3의 손익분기를 넘는 것이 확인된 뒤 추가한다. PG가 Pack 때문에 이미 도입됐다면 입금 자동화의 첫 선택은 2% 계좌이체가 아니라 가상계좌다.

**더 올리지 않는 이유**

- **제품이 아직 증명되지 않았다.** Pack 핵심 기능이 미구현이고 GEO 점수와 AI 언급률의 상관도 약하다(ρ<0.3). 결과를 보여주기 전에 월 99만원을 기본가로 받기 어렵다.
- **파트너 대부분이 작은 회사다.** 광고대행업 사업체의 83~85%가 1~4인이라 월 99만원은 큰 고정비다.
- **올리기는 쉽고 내리기는 어렵다.** Founding 가격을 "12개월 한정"으로 걸어두면 정식가로 넘어가는 명분이 이미 있다. 파일럿에서 재판매 가격이 높게 나오면 Partner를 59만~69만원으로 올려 시험한다.

**더 내리지 않는 이유**

- 시장이 작아 149,000원으로는 중심 시장 10%를 확보해도 ARR 5천만원대에 머문다(§6.1).
- 원가가 가격 하한을 만들지 않으므로, 할인은 가격이 아니라 포함 학원 수로 준다.

### 6.5 AI 검색 추적 agent·서비스

가격 미정. 개발 시점에 외부 API 조회 원가(질문 수 × 엔진 수 × 조회 주기)와 경쟁 추적 제품 가격(Adplorer 4.9만원·Otterly $29)을 함께 보고 정한다. 자동 agent와 사람이 해석해 주는 서비스(월간 리포트·다음 수정 제안) 두 형태를 검토한다.

## 7. 파트너 ROI를 어떻게 신뢰시키나

"AI 인용이 올라 학원 원생이 는다"는 약속은 지금 할 수 없다(§3). 따라서 설득을 GEO 효과가 아니라 **우리가 측정할 수 있는 것**에 건다.

### 7.1 파트너가 이익을 보는 세 경로

| 이익 경로 | 내용 | GEO 효과 증명 필요 | 확인까지 |
|---|---|---|---|
| **① 작업 시간 절감** | 지금 손으로 하던 진단·수정안 작성·보고서 작업 감소 | **아니요** | **4주 (파일럿)** |
| ② 신규 매출 | 학원에 "AI 검색 관리" 상품을 추가 판매 | 일부 (학원이 원하면 팔림) | 2~3개월 |
| ③ 고객 이탈 방지 | 매달 보고서로 기존 유지보수 계약을 유지할 명분 | 아니요 | 6~12개월 |

**①을 앞세운다.** 가장 빨리 숫자로 보여줄 수 있고 GEO 효과와 무관하다.

### 7.2 설득 문장

> 학원 1곳당 요금 2.5만원은 직원 1시간 인건비다. 학원 한 곳에 쓰는 작업 시간이 한 달에 1시간 넘게 줄면 이득이고, 학원에 새로 파는 매출은 덤이다.

시급 2~3만원은 가정이므로 파일럿 인터뷰에서 파트너별 실제 인건비로 바꾼다. **"학원당 월 5만원"은 재판매 업체가 원가의 2배는 받는다는 가정일 뿐 확인된 숫자가 아니다.** 실제 기준은 학원이 GEO 관리에 낼 금액이며 파일럿에서 측정한다.

### 7.3 증명 절차

**1. 계약 전: 파트너가 관리하는 학원 사이트를 무료 일괄 스캔**
- 약속이 아니라 이미 있는 문제를 보여준다. 예: "관리 중인 학원 사이트 20곳 중 14곳은 정보가 이미지 안에만 있어 AI가 읽지 못한다."
- 원가는 거의 0원이고, 파트너가 **자기 고객의 문제**를 직접 확인한다.

**2. 4주 파일럿: 파트너 3~5곳 × 학원 3곳씩**
- **시작 전:** 학원 1곳당 월 작업 시간을 인터뷰로 기록 (진단, 수정안 작성, 보고서 작성)
- **파일럿 중:** 제품이 스캔 → 수정안 승인 → 적용 확인 시각을 자동 기록
- **종료 후:** 파트너별 ROI 한 장. 예: "학원당 월 작업 3시간 → 40분, 절감 약 6만원 vs 요금 2.5만원"
- **동시에 기록:** 파일럿 기간 학원에 GEO 상품을 제안한 횟수, 수락 수, 받은 가격. **이 숫자가 Partner 가격의 실제 근거가 된다.**

**3. Founding 조건을 신뢰 장치로 쓰기**
- 29만원 할인의 대가로 작업 데이터 공유·사례 공개 동의를 받는다.
- 첫 파트너들의 실제 수치가 다음 파트너를 설득하는 영업 자료가 된다. 우리의 주장이 아니라 다른 에이전시의 결과를 보여준다.

**4. 위험을 우리가 먼저 지기**
- 파일럿은 무료 또는 보증금만 받고, 연간 계약 없이 월 단위 해지
- 학원 제안서 템플릿, 재판매 가격 가이드, 파트너 로고 보고서 샘플을 제공해 **파트너의 판매 비용을 우리가 낮춘다**

### 7.4 쓰지 않을 문구

"AI 인용 상승", "원생 증가", "매출 몇 % 증가" 보장. 추적 agent가 나오고 전후 데이터가 쌓이기 전까지 쓰지 않는다.

### 7.5 파일럿이 실패하면

학원당 절감 시간이 1시간에 못 미치고 학원 재판매도 없다면, 가격이 비싼 게 아니라 **제품이 파트너의 실제 작업을 줄이지 못하는 것**이다. 그때는 가격이 아니라 제품 범위를 다시 본다.

## 8. 교육 도메인: 대형 학원과 소형 학원

AI 서버 서빙 도메인은 `news`/`ecommerce`/`education`이고, `tech_blog`는 학습 데이터 부족으로 제외됐다(`GeoEvaluationRequest.SUPPORTED_DOMAINS`). 교육으로 깊게 파되, **`education` 하나 안에서 고객사가 둘로 갈린다.**

| | 대형 학원·프랜차이즈 | 소형 학원 |
|---|---|---|
| 페이지 구성 | 지점·강사·커리큘럼 수백 페이지 | 20~50 페이지 |
| 외부 광고·배너 | **노이즈.** 제거해야 평가가 정확하다 | **노이즈 아님.** 광고처럼 보여도 자기네 PR이라 전부 유효 데이터 |
| 텍스트/이미지 비율 | 텍스트 비중 높음 | **이미지 비중 높음.** 본문이 이미지 안에 있어 추출이 거의 안 된다 |
| 핵심 수정 항목 | 노이즈 분리, 지점 페이지 간 엔티티 일관성 | **정보를 이미지에만 두지 말 것.** 이미지 위치를 짚고 텍스트를 HTML로 옮기는 패치 |
| 도달 경로 | 담당 파트너, 프랜차이즈 본사(Partner Plus), 또는 인하우스 담당자의 Pack 직접 구매 | **담당 파트너의 Partner 플랜** |

**가격·제품에 미치는 영향**

- **학원 원장에게 직접 파는 경로를 주력으로 두지 않는다.** 경쟁사 분석은 "기술 인력이 없는 소상공인이 생성된 코드를 신뢰해 직접 적용한다"를 가장 약한 가정으로 꼽았다. 코드를 검토·적용할 수 있는 파트너가 사고, 학원은 결과를 받는다.
- **대형 학원은 학원 1곳 = 페이지 10개 한도를 넘는다.** 지점 수백 페이지는 Partner Plus 견적이나 프랜차이즈 본사 계약으로 받는다.
- **노이즈 필터는 가격으로 막지 않고 학원 단위 설정으로 둔다.** 대형은 기본 ON, 소형은 OFF다. 정확도를 좌우하는 설정을 상위 플랜 전용으로 막으면 하위 플랜 결과가 틀려진다.
- **이미지 의존 경고는 무료 Scan의 훅이다.** AI 응답에 이미 `insufficient_content`, `content_warning`, `main_content_length`가 있어 추가 원가 없이 보여줄 수 있다. 파트너 영업용 일괄 스캔(§7.3)의 핵심 근거가 된다.
- **소형 학원은 원가가 아니라 처리량을 깎는다.** 이미지 비중이 높으면 Jsoup에서 텍스트가 안 나와 Playwright 폴백률이 오른다. Playwright는 건당 수 초의 CPU를 쓰고 OCI 무료 VM은 2 OCPU다. 병목은 GPU가 아니라 백엔드 VM의 Chromium이며, 가격이 아니라 202 비동기 전환으로 푼다.

## 9. 검증 계획과 출시 조건

경쟁사·시장 조사는 공급자 조사일 뿐 고객이 돈을 낸다는 증거가 아니다. 아래 기준은 경쟁사 분석 문서 §14~15와 파트너 시장규모 분석 문서 §9의 초기 제안값이며, 업계 표준이 아니다.

| 대상 | 검증 방법 | 통과 기준 |
|---|---|---|
| 영업 퍼널 | 1차 영업 대상 60~80곳 + 후보 추가로 100곳 접촉 | 미팅 15~20곳, 유료·보증금 파일럿 5곳 이상 |
| 가격 | 파일럿 파트너에게 Founding 290,000원 / Partner 490,000원 실제 견적 제시 | 구두 선호가 아니라 **보증금·유료 계약**. 월 199,000원 이상 지불 의사 확인이 최소선 |
| 파트너 ROI (§7) | 4주 파일럿, 작업 시간 전후 기록 | **학원당 월 1시간 이상 절감**, 학원 재판매 제안·수락·가격 기록 확보 |
| 유지 | 파일럿 후 유료 전환 파트너 관찰 | 2개월 차 유지율 70% 이상, 등록 학원 수 증가 |
| Pack 품질 | 허가 URL 15~30개, 전문가 2인 gold set | 상위 문제 precision 80%, 패치 구문 유효성 90%, 적용 성공률 70%, 즉시 롤백 5% 이하 |

**Pack 품질 기준을 통과하기 전에는** "자동 개선", "검증된 효과", "AI 인용 상승"을 외부 문구로 쓰지 않는다.

**적합 기업 100곳에 접촉하고도 유료 파트너가 2곳 미만이면**, 기업 수 부족보다 GEO 가치 전달·재판매 가능성·반복 사용 필요성을 먼저 점검한다.

## 10. 구현 상태와 코드 영향

- **판매 가능한 것은 무료 Scan뿐이다.** Spring 주문 경로는 `/evaluate`만 호출한다. 개선안 생성은 AI 서버의 팀 테스트용 `/diagnose`에만 있다.
- **Pack에 필요한 것은 전부 미구현이다.** `/diagnose` 제품 연동, 위치(selector·Schema path)별 diff, 구문·Schema·본문 일치 validator, 적용 후 재수집 비교.
- **Partner에 필요한 것도 미구현이다.**
  - 파트너 계정 – 학원 작업 공간 – 팀원 구조
  - 학원 수 기준 한도와 학원당 월 페이지 한도
  - 파트너 로고 보고서(PDF·공유 링크)
  - URL 일괄 등록(영업용 일괄 스캔)
- **파트너 ROI 측정용 이벤트 기록이 필요하다.** 스캔·수정안 생성·승인·적용 확인 시각을 저장해야 §7.3의 작업 시간 비교가 가능하다.
- 결제, 사용량 제한, 요금제 변경 API, 재분석 이력은 미구현이다.
- **결제 구현 순서:**
  1. Partner 파일럿: 주문번호·입금기한·`PENDING_PAYMENT → PAID` 상태, 중복 불가능한 관리자 입금 확인, 크레딧·구독 1회 부여, 처리자·시각 감사 로그.
  2. Pack 출시: 토스페이먼츠 한 곳만 연동. 결제 ID·주문금액 검증, 승인 응답과 웹훅 멱등 처리, 결제완료 후 크레딧 1회 부여, 취소·환불 상태 기록.
  3. 필요 시 가상계좌: 계좌 발급은 결제완료가 아니며 실제 입금 웹훅에서만 `PAID`로 전환.
  4. 카카오페이·토스페이 직접 어댑터, 여러 PG를 위한 범용 추상화, 은행 계좌 스크래핑은 초기 범위에서 제외.
- `Client.ClientPlan{FREE, BASIC, PRO, ENTERPRISE}`는 FREE=기본(Scan·Pack 구매), BASIC=Founding Partner, PRO=Partner, ENTERPRISE=Partner Plus로 매핑된다. Pack 크레딧 잔액과 추적 agent 구독은 plan 값 하나로 표현되지 않으므로 별도 잔액·구독 필드가 필요하다.
- 대형/소형 학원 구분과 노이즈 필터 토글이 없다. 현재 `Order.DomainStatus`는 `EDUCATION` 하나다.

## 11. 미확정 / 확인 필요

- **학원이 GEO 관리 상품에 낼 금액과 파트너의 실제 인건비.** 파일럿에서 측정한다. 학원당 월 5만원 이상이면 Partner 가격 상향 여지가 있고, 못 미치면 49만원이 비싸다.
- Adplorer 플랜별 관리 가능 사이트 수, 개인 LLM 최상위 요금제 가격(2026-09 기준)은 재확인이 필요하다.
- 1차 영업 대상 60~80곳과 전국 180~450곳은 공개 검색 포착률 가정이 들어간 추정이다. 관리 학원 수·사이트 수정 권한·월간 보고 계약 여부는 영업 인터뷰로 확인한다.
- **추적 agent 개발 시 확인할 것.** 네이버 AI 브리핑 조회 가능 여부(학부모 수요는 네이버 비중이 클 가능성이 높다)와 API 응답이 실제 앱 화면과 다를 수 있다는 점.
- 경쟁사 가격은 2026-08-07 기준이다. 사업계획서에 쓰기 전에 공식 페이지를 다시 확인한다.
- 소형 학원 사이트의 Playwright 폴백률·텍스트 추출 실패율은 미측정이다.
- 생성까지 로컬로 옮길 경우의 Pack 3.1단위·일 3,200건은 산술 추정이다. 그 경로를 택할 때 vLLM multi-LoRA 실측으로 대체한다.
